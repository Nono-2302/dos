📦 Étape 1 : Désinstaller Docker DesktopOuvrez les Paramètres de Windows (touches Windows + I).Allez dans Applications > Applications installées.Dans la barre de recherche, écrivez : Docker Desktop.Cliquez sur les trois petits points à droite, choisissez Désinstaller, puis suivez les instructions à l'écran.🐧 Étape 2 : Supprimer complètement Linux (WSL et Ubuntu)Pour effacer la machine virtuelle Linux ainsi que les modules Python (scapy, requests) installés à l'intérieur, ouvrez l'application PowerShell en mode Administrateur et tapez ces trois lignes l'une après l'autre :powershellwsl --unregister Ubuntu
Utilisez le code avec précaution.(Cette commande efface instantanément la distribution Ubuntu et l'intégralité de ses fichiers internes).powershellwsl --update --rollback
Utilisez le code avec précaution.Allez ensuite à nouveau dans vos Paramètres Windows > Applications > Applications installées, cherchez Sous-système Windows pour Linux (ou Windows Subsystem for Linux) et cliquez sur Désinstaller.📡 Étape 3 : Supprimer les pilotes réseau Windows (Npcap)Si vous aviez installé le pilote spécifique pour l'analyse réseau sur Windows (requis pour Scapy sans WSL) :Dans vos Applications installées sur Windows, cherchez Npcap.Cliquez sur Désinstaller.📁 Étape 4 : Supprimer le dossier de votre BureauEnfin, il ne vous reste plus qu'à aller sur votre Bureau Windows :Faites un clic droit sur votre dossier de script (ex: Nouveau dossier ou LaboDocker).Choisissez Supprimer (ou utilisez le raccourci Maj + Suppr pour le vider définitivement sans passer par la Corbeille).Une fois ces quatre étapes validées et après un petit redémarrage de votre ordinateur, 100 % de l'espace occupé par ces outils de laboratoire sera récupéré et votre PC sera totalement nettoyé.Si vous le souhaitez, je peux vous aider à vérifier s'il reste des fichiers temporaires ou des résidus cachés dans votre dossier utilisateur.
